# LCD_ILI9488 — восстановлено из образа B (в образе A та же шина FSMC Bank1, `FSMC_BANK1` функции 0x08006512…)

## Шина
| Параметр | Значение | Доказательство |
|---|---|---|
| Команда / данные | 16-бит записи `strh` по **0x60000000** (CMD) и **0x60200000** (DATA) | mem-лог: 31 запись CMD, 82 записи DATA, 5 чтений DATA (0x60200000) в B |
| RS | PE4 = FSMC A20 (бит адреса 21 ⇒ +0x200000) | GPIO 0x0801549C (маска 0xFF90 содержит PE4) |
| CS | **ручной GPIO PE3** (не NE1!): LOW в `LCD_Init` и на время `LCD_WriteBuffer` (0x08015920), HIGH после (0x0801593C) | PE3 в списке OUT_PP 0x08015446 |
| RESET | PE5, `LCD_Reset` 0x08015252: Low → delay_soft(400) → High → delay_soft(400) | см. 0x08015252–0x0801526C |
| Подсветка | PC9: Reset при инициализации (0x0801546E), SetBits в конце `LCD_Init` (0x080156C4) | |
| FSMC | Bank1 NORSRAM1, SRAM, 16 бит, без mux, без burst, WriteOperation=Enable (0x1000), **ExtendedMode=выкл** | `FSMC_NORSRAMInit` вызов 0x080154C2; поля: sp+12=0x10 (0x080154A0), sp+36=0x1000 (0x080154A8), sp+44=0 (0x080154BA) |
| Тайминги | Read/Write общий: **ADDSET=0, ADDHLD=0, DATAST=1, BUSTURN=0, CLKDIV=0, DATLAT=0, режим A** | timing-struct sp+92..116 (0x08015402–0x0801540A); WriteTimingStruct (sp+64..88 нулевой) не используется, т.к. ExtendedMode=0 |
| Включение | `FSMC_NORSRAMCmd(0,1)` 0x080154CA; тактирование: APB2 0x1E0 (GPIOC–GPIOE+…), AHB 0x100 (FSMC) | 0x08015420, 0x08015428 |

**Расчёт:** цикл записи ≈ (ADDSET+1)+(DATAST+1) = 3 HCLK ⇒ 25 нс @120 МГц (41,7 нс @72 МГц). Это быстрее типовых 50 нс write cycle ILI9488 (datasheet, внешний факт); работает на практике у клонов, но на STM32F103@72 МГц запас мал (**риск**, проверять на плате). Чтение (5 обращений) при DATAST=1 слишком быстро для штатного read cycle ≈150 нс — возможные ложные чтения ID/пикселей.

## Последовательность инициализации (`LCD_Init_ILI9488` 0x0801555A, извлечено автоматически из FSMC-записей)
1. `LCD_GPIO_FSMC_Init` (0x080153E4) → PE5 Reset → `LCD_Reset` → PE3 Reset (CS low).
2. Команды (адрес записи команды → код; данные в порядке следования):

| Адрес | CMD | Данные |
|---|---|---|
| 0x0801557A | E0 (PGAMCTRL) | 00 13 18 04 0F 06 3A 56 4D 03 0A 06 30 3E 0F (15) |
| 0x080155BC | E1 (NGAMCTRL) | 00 13 18 01 11 06 38 34 4D 06 0D 0B 31 37 0F (15) |
| 0x080155FC | C0 | 18 17 |
| 0x08015608 | C1 | 41 |
| 0x08015610 | C5 | 00 40 00 40 |
| 0x08015624 | 36 (MADCTL) | **6A** |
| 0x0801562C | 3A (COLMOD) | **55** (16 бит/пиксель, RGB565) |
| далее | B0 00; B1 A0; B4 01; B6 02 22; E9 00; F7 A9 51 2C 82 | (после `b 0x08015654` над литеральным пулом; значения подтверждены чтением листинга 0x08015654–0x08015698) |
| конец | 20 (инверсия off), 11 (sleep out) → **delay 120** (0x0801730E, единицы TIM2) → 29 (display on) → 2C | 0x0801569C–0x080156A6 |
3. `delay_soft(100)` → `LCD_Clear` (0x08015522: дважды `LCD_FillRect(0,0,480,320,0)` с `delay_soft(50)`) → `delay_soft(6000)` → подсветка PC9 = 1.

**MADCTL 0x6A** = MX(бит6)=1, MV(бит5)=1, BGR(бит3)=1 (бит1 зарезервирован) ⇒ ландшафт 480×320, порядок цветов BGR. **COLMOD 0x55** ⇒ RGB565, значения пикселей пишутся как 16-бит слова.

## Функции
| Адрес | Имя | Подтверждённое поведение |
|---|---|---|
| 0x080152EE | LCD_SetWindow(x0,y0,x1,y1) | CMD 2A: x0,x1 (r0,r2); CMD 2B: y0,y1 (r1,r3) |
| 0x0801581A | окно-обёртка | вызов `(0,0,0x1DF,0x13F)` в 0x080148FE/0x08014902 = весь экран |
| 0x08015914 | LCD_WriteBuffer(count,buf) | CS low, цикл `ldrh/strh` в 0x60200000, CS high |
| 0x080154D4 | LCD_FillRect(x,y,w,h,color) | вызов `(0,0,480,320,0)` из `LCD_Clear`; тело не перепроверялось (confidence low) |

## Не установлено
Шрифты/текстовый рендер (см. STRINGS_AND_RESOURCES.md), DMA для LCD не используется (в B DMA2 только SPI3-путь без вызовов). Виджеты/кнопки — картинки с NAND (NAND_TOSHIBA.md).
