# SD_CARD — SPI2, режим SPI (образ B; в A — копия кода `0x08005D7E…`)

| Параметр | Значение | Доказательство |
|---|---|---|
| Интерфейс | **SPI2 аппаратный**: SCK PB13, MISO PB14, MOSI PB15 (AF_PP), CS PB12 (OUT_PP, ручной), CD PB11 (IPU) | GPIO_MAP.md; `SD_SPI2_Init` 0x08014AC8 |
| Клок | APB1 бит 0x4000 (SPI2) и APB2 0x18 (GPIOB, GPIOC) | 0x08014AD2, 0x08014ADA |
| SPI_Init | Master, 8 бит, CPOL=High (0x0002), CPHA=2-й фронт (0x0001), NSS soft (0x200), **prescaler 0x38 = /256**, MSB first (word3=0x38) | вызов 0x08014B82 (структура стека) |
| Скорость | старт ≈ 60 МГц/256 = 234 кГц; после инициализации `SD_SetSpeed(1)` (0x08014B92, вызов 0x08014DC4) переключает на более быстрый делитель (значение по индексу не расшифровано) | |
| Байтовый обмен | `SD_SPI_ReadWriteByte` 0x08014BE8: ждёт TXE, пишет DR, ждёт RXNE, читает DR | 0x08014BEE–0x08014C0E |
| Карта вставлена | `ReadInputDataBit(GPIOB,0x800)` 0x08014D0C | |

## Инициализация `SD_Init` (0x08014CFA) — порядок команд восстановлен по последовательности вызовов `SD_SendCmd`(0x08014C12)/`0x08014C94` с константными аргументами; ветвление v1/v2 выведено по порядку, детально не трассировалось
1. ≥74 тактов (цикл `SD_SPI_ReadWriteByte(0xFF)`, 0x08014D18).
2. **CMD0** (arg 0, CRC 0x95) 0x08014D2C; **CMD8** (arg 0x1AA, CRC 0x87) 0x08014D48.
3. Ветка SD v2: цикл **CMD55 (0x37) + ACMD41 (0x29)** (0x08014D80/0x08014D8E, второй аргумент — вычисляемый, вероятно HCS 0x40000000); **CMD58 (0x3A)** (0x08014E40) для чтения OCR (признак SDHC); **CMD16 (0x10), blocklen 0x200** (0x08014DD6) — для SD v1/SDSC.
4. Ветка v1/MMC: ACMD41, fallback **CMD1** (0x08014DA8).
* Поддержка **SDHC**: есть (CMD8/CMD58/ACMD41). **SDXC/exFAT: не обнаружено**.
* Чтение/запись секторов: функции 0x08014F12, 0x08014F44, 0x08014FA8 (вызывают `SD_SendCmd` и `SD_SetSpeed`); адресация, CMD17/CMD24, токены — **не расшифрованы**. DMA для SD не используется.
* Файловая система: строка **"FAT32"** (B 0x0801346C, ссылка из 0x0801338E) и таблицы OEM↔Unicode (кодовая страница 936/GBK, FatFs-подобные, см. STRINGS_AND_RESOURCES) ⇒ FAT32 (FatFs-совместимый драйвер) с длинными именами; FAT16/exFAT явно не найдены. Фильтр расширений: ".gcode" (0x0801C81C), ".bmp" (0x08018D04).
