# MEMORY_MAP

Размер файла 262144 B (0x40000) = 256 КБ Flash, база 0x08000000 (проверено: содержимое по смещению 0 — таблица векторов с MSP=0x20007FC8). **Последний ненулевой байт: 0x0803E8C7.** SHA-256 дампа: `eb590a761a987de73b56aa42e4dbc61e70cd631e254b94f3dd5ba389951814b3`.

> **Корректировка исходной постановки:** дамп содержит **два независимых образа** — загрузчик A (0x08000000) и приложение B (0x08010000). Адреса `0x0801xxxx` из задания принадлежат образу B (его `__main`-подобный стартовый стаб на 0x08010130, `SystemInit` 0x0801D074 и т.д.). Файл по смещению 0x130 (0x08000130) — аналогичный стаб образа A.

Фактически используется Flash: A ≈ 0xEE80 (61,1 КБ) + B ≈ 0x13518 (78,3 КБ) + 0x68 = ≈ 139,6 КБ; свободно ≈ 120 КБ. Загрузчик/приложение: образ A проверяет и запускает B (см. SOFTWARE_ARCHITECTURE.md). Сжатых/зашифрованных блоков **не обнаружено** (scatter-обработчики — copy/zero, не LZ; не перепроверено дизассемблированием 0x08009E68/0x0801E08A).
Полная построчная карта: `resources/binary_regions.csv`.

## RAM (STM32F103VC: 48 КБ, 0x20000000–0x2000BFFF)
| Диапазон | Образ | Назначение |
|---|---|---|
| 0x20000000–0x2000010C | A | RW-данные (копия из Flash) |
| 0x2000010C–0x20007FC8 | A | ZI (0x7EBC Б); MSP стартует с 0x20007FC8 (верх этой зоны; стек/куча внутри ZI/stack-секции) |
| 0x20000000–0x200001F0 | B | RW-данные |
| 0x200001F0–0x20006C08 | B | ZI (0x6A18 Б); MSP=0x20006C08 |
| 0x20000068 | B | структура тика TIM2 |
| 0x20000078 | B | состояние UART-кольца; буфер 0x200048B4 (250 Б) |
| 0x2000389C | B | буфер страницы NAND |
| 0x200067A0 | B | копия блока настроек |
Из 48 КБ используется ≤ 32 КБ (A) / ≈27 КБ (B). Выше 0x20007FC8 RAM не используется.

## Периферийные области, к которым обращается код
0x40000000–0x40023000 (APB1/APB2/AHB), FSMC: 0x60000000 (Bank1 LCD), 0x70000000 (Bank2 NAND: DATA 0x70000000, CMD 0x70010000, ADDR 0x70020000), регистры FSMC 0xA0000000, SCB/NVIC/SysTick 0xE000E000-блок, bit-band 0x42000000 (AFIO).
