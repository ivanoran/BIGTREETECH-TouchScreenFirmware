# PORTING_GUIDE — перенос на PlatformIO (STM32F103VCT6)

**Предусловие:** реализацию начинать только после снятия блокирующих вопросов из UNRESOLVED.md (особенно: фактический кристалл/частота, дамп NAND, формат шрифтов, смысл токенов протокола).

## 1. Что переносить как есть / переписывать / зависит от платы
| Модуль | Решение | Основание |
|---|---|---|
| Протокол принтера (A-коды, G1), разбор строк, кольцевой буфер | **Переносить логику**, переписать код (printf/`strcmp`) на C++ | строки известны (UART_PRINTER.md); UART 115200 8N1 |
| Меню/экраны/состояния печати | **Переписать** по таблицам сообщений и логике `Main_Task_UI`; предварительно сопоставить номера картинок NAND со страницами | логика не разобрана построчно |
| Графика UI (61+ картинок 480×320 RGB565) | **Данные NAND**: считать с оригинальной платы (дамп NAND 128 МиБ, 3 блока/картинка) или перегенерировать | NAND_TOSHIBA.md |
| Шрифты | неизвестны — взять готовые (GBK/ASCII) или извлечь после расшифровки | UNRESOLVED |
| FatFs/FAT32 | **Заменить** на FatFs (ChaN) + диск-драйвер SPI2 (`SD_SPI_ReadWriteByte`, `SD_Init` последовательность CMD0/8/55+41/58/16) | SD_CARD.md |
| ILI9488 драйвер | **Переписать** по таблице команд (LCD_ILI9488.md); FSMC Bank1 16 бит, A20=RS, CS руками | |
| NAND драйвер | **Переписать** (HAL/LL или SPL): команды 0xFF/0x90/0x70/0x00-0x30/0x80-0x10/0x60-0xD0, 2048+64, 5 циклов адреса | |
| XPT2046 | **Переписать** (bit-bang как в оригинале или SPI1); фильтр 30 замеров, trimmed mean (4..25)/22; калибровка — заново (оригинальные коэффициенты неизвестны) | TOUCH_XPT2046.md |
| Тактирование | **Заменить**: PLL×9 (72 МГц) для настоящего STM32F103; пересчитать TIM2 (PSC 71/ARR 999 уже даёт 1 мс при 72 МГц), TIM5 PSC, FSMC тайминги, SPI2 делитель | CLOCK_TREE.md |
| Загрузчик A | **Не переносить** (или заменить на штатный DFU/SD-update); приложение собирать с VTOR=0x08010000 только при необходимости сохранить совместимость с A | |
| Буззер, DAC(PA4), PE2, PE0 | реализовать по GPIO_MAP.md; назначение PA4/PE2/PE0 выяснить на плате | |

## 2. Архитектура проекта PlatformIO
```
platformio.ini            ; board = genericSTM32F103VC, framework = stm32cube (HAL) или libopencm3/SPL
src/main.cpp              ; суперцикл: tick(), comm.poll(), ui.poll(), touch.poll()
lib/hal_board/            ; АППАРАТНО-ЗАВИСИМЫЙ слой
  board_pins.h            ; все пины из GPIO_MAP.md
  clock.cpp               ; PLL x9, APB1/2
  gpio.cpp, fsmc_lcd.cpp, fsmc_nand.cpp, spi_sd.cpp, uart_printer.cpp, tim_tick.cpp, tim_buzzer.cpp, dac.cpp
lib/drivers/              ; тонкие драйверы поверх hal
  ili9488.{h,cpp}  nand_tc58.{h,cpp}  xpt2046.{h,cpp}  sd_spi_diskio.cpp
lib/core/                 ; АППАРАТНО-НЕЗАВИСИМЫЙ слой
  printer_proto.{h,cpp}   ; сериализация A-кодов, парсер ответов (A0V..., J33, END)
  ui_screens.{h,cpp}      ; экраны, кнопки, диалоги, таблица сообщений
  image_store.{h,cpp}     ; интерфейс "картинка N" (NAND/SD/Flash — подменяемо)
  settings.{h,cpp}        ; блок 100 Б, версия, CRC (в оригинале CRC не найден)
  fs_files.{h,cpp}        ; список .gcode, пагинация
test/                     ; unity: парсер протокола, фильтр касаний, формат NAND-адресов
```
Интерфейсы (абстракции): `ILcd{ setWindow, writePixels, fillRect }`, `INandStore{ readPage(row,col,buf), eraseBlock, readId }`, `ITouch{ readRaw(x,y), pressed() }`, `IBlockDevice{ read(sector), write }`, `ISerial{ write, readLine }`, `IClock{ ms() }`.

## 3. Порядок реализации
1. Тактирование + SWD-проверка; **считать IDCODE/маркировку** (STM32 vs GD32/APM32).
2. GPIO + FSMC Bank1 + ILI9488 init (последовательность из LCD_ILI9488.md) → тест заливки/картинки; подобрать FSMC тайминги под 72 МГц (DATAST≥2 при необходимости).
3. TIM2 1 мс тик + `delay_ms`; TIM5 PWM-зуммер.
4. USART1 115200 + кольцевой буфер + парсер строк; PA8 reset.
5. XPT2046 (опрос PC5, фильтр) + собственная калибровка.
6. NAND: ReadID (ожидаются байты TC58BVG0S3H: 0x98 0xF1 — внешний факт), чтение страниц, вывод картинки 480×320 (150 страниц × 1024 px) для сверки с оригиналом.
7. SD SPI2 + FatFs; список файлов `.gcode`; печать с SD по протоколу A-кодов.
8. UI-экраны, диалоги, сообщения (STRINGS_AND_RESOURCES.md), настройки.
9. Регрессия против оригинала на плате (логический анализатор на UART и FSMC).

## 4. Зависимости и тесты
* Зависимости: HAL/SPL, FatFs, (опционально) LVGL — **не рекомендуется** без решения по шрифтам и графике.
* Тесты на стенде: сравнить UART-трассу оригинал/порт; сравнить FSMC-поток команд LCD (E0…2C); проверить, что `Show_NAND_Image(n)` даёт идентичные кадры; touch: raw X/Y для углов.

## 5. Риски
| Риск | Описание | Митигация |
|---|---|---|
| Частота/чип | 120 МГц в оригинале ≠ спецификации STM32F103 | подтвердить кристалл; перенастроить все тайминги |
| FSMC тайминг LCD | 25 нс write-цикл @120 МГц, на 72 МГц ≈ 41,7 нс | увеличить DATAST/ADDSET при артефактах |
| PC4 (CS тача) IPU | оригинал работает с «подтяжкой» | OUT_PP в порту |
| NAND ресурсы | графика только в NAND оригинала | сделать дамп NAND (read-all) до любой записи/стирания |
| Протокол | смысл A-кодов выведен из UI | сверка с прошивкой принтера/логами |
| Шрифты | формат неизвестен | заменить/восстановить |
| Единицы времени | 1 тик TIM2 = 0,6 мс при 120 МГц | не копировать «магические» задержки; задавать в мс |
