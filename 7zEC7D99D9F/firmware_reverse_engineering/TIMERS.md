# TIMERS — таймеры, звук, задержки

| Блок | Конфигурация | Функция / адреса | Вывод |
|---|---|---|---|
| **TIM2** | RCC APB1ENR bit0; **PSC=0x47 (71), ARR=0x3E7 (999)**; DIER.UIE=1, CR1.CEN=1; NVIC ISER0 bit28 (IRQ28) | `TIM2_Tick_Init` 0x0801728C (0x0801729E ARR, 0x080172A0 PSC, 0x080172A8 DIER, 0x080172B0 CR1, 0x080172BE NVIC); вызов из `B_main` 0x0801016E | Период = 72·1000/f_TIM2: **0,6 мс при 120 МГц** (1 мс только если таймер = 72 МГц) |
| TIM2 ISR | `TIM2_IRQHandler` 0x080172C4: если UIF → `++[0x20000070]` (тик), `++[0x2000006C]`; если флаг `[0x20000068]`≠0: счётчик `[0x20000074]` уменьшается, по нулю вызывается `0x080175A6` (выключение зуммера) и флаг сбрасывается; затем UIF сбрасывается | 0x080172CA–0x080172FC | |
| **TIM5 CH3** | PA2 AF_PP; TimeBase: **ARR=0x31F (799)**, PSC=аргумент (main: 0x28), Counter up, ClockDiv 0; OC: режим **0x70 (PWM2)**, OutputState Enable; preload (0x08012064 с 0x8); CCR3 пишется 0x320 (0x080175A0); TIM5 Cmd | `Buzzer_TIM5_PWM_Init` 0x08017520; вызов `B_main` 0x08010164 `(0,0x28)` | f_PWM ≈ f_TIM/(PSC+1)/800 = **≈3,66 кГц @120 МГц** (≈2,2 кГц @72 МГц); регулировка громкости — CCR3 (0xC8 / 0x320 в разных местах) |
| SysTick | `SysTick_Config` 0x08017198 (LOAD=Core/1000−1, prio 0xF0, CTRL=7) | **нет вызовов** ⇒ SysTick в B не используется (векторы SysTick=0x0801261C: бесконечный цикл) | |
| TIM1/3/4/8, WWDG/IWDG, RTC | **не используются в B** (нет обращений к базовым адресам; IWDG отсутствует) | — | — |
| A (загрузчик) | `A_TIM2_IRQHandler` 0x08008706, TIM2 0x080086C8, TIM5 0x08008A3A, SysTick 0x08008560 | | |

## Задержки
| Функция | Адрес | Единица |
|---|---|---|
| `delay_ms_tim2(n)` | 0x0801730E (+`tick_elapsed` 0x08017306, `0x08017300`) | n × период TIM2 (≈0,6 мс @120 МГц) |
| `delay_soft(n)` | 0x080164DC | n×200 итераций RAM-цикла; **не калибрована**, зависит от SYSCLK |
| `delay_us_like(n)` | 0x08016EE0 (тач) | n×18 итераций RAM-цикла |
| `0x080101E8` | `subs r0,#1; bhs` | чистый счётный цикл (мёртвый код) |
