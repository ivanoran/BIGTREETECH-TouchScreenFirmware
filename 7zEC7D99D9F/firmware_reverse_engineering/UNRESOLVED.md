# UNRESOLVED — нерешённые вопросы и что проверить

| # | Вопрос | Что известно / адреса | Как установить |
|---|---|---|---|
| 1 | **Реальный кристалл и частота** (STM32F103VC vs GD32F303VC/др.) | PLL×15=120 МГц, APB1=60 МГц (CLOCK_TREE.md); нет чтения IDCODE | маркировка чипа; прочитать DBGMCU_IDCODE (0xE0042000) / размер флеш по SWD |
| 2 | Шрифты и кодовые таблицы | A 0x0800A03E–0x0800ED54; B 0x0801EA8A–0x08023308; рендер 4B/строка, 16×16, 8×16 — нечитаемо | найти код вывода текста (функции с обращением к этим адресам по литералам), определить ширину/высоту/порядок бит; визуальная проверка |
| 3 | Формат/смысл блока настроек 0x0803E864 (100 Б) и функция **записи** во Flash | чтение — `Param_ReadFlash` 0x0801CF40; массив u16 0x259–0x26C | трассировать записи в RAM 0x200067A0.., найти FLASH_ErasePage/ProgramHalfWord вызовы |
| 4 | Калибровка тача и формулы пересчёта | Touch_Poll 0x08016BB0, константы double 307.2 / 4915.2; «Touch Screen Adjust OK!» | трассировка 0x08016BB0–0x08016D90, дамп RAM после калибровки |
| 5 | PC4: OUT_PP затем IPU (0x08016A50→0x08016AAA) | CS тача может работать через подтяжку | осциллограф на PC4 / XPT2046 CS |
| 6 | Назначение PE2, PE0, PA4 (DAC), TIM5 громкость | 0x080171F4, 0x0801723A, 0x0801762C(PE0), 0x080175C0 | трассировка вызывающих; щуп на плате |
| 7 | Смысл токенов ответа принтера `A0V…A7V, A20V, A44V, A45V, J33, END` и команд `A38/A40/A41/A42/A43/MCA39` | UART_PRINTER.md; разбор 0x0801C574–0x0801C7EC | лог UART с реальным принтером, сверка с прошивкой принтера |
| 8 | Имена/формат файлов обновления ресурсов на SD (SD→NAND) | `SD_to_NAND_Loader` 0x08014702, `0x08014250`; имя файла не найдено как ASCII (возможно, формируется `0x41+i`) | трассировка 0x08014702, дамп SD-карты с оригинальным набором |
| 9 | ECC/bad-block/spare в NAND | B: нет чтений spare; A: spare-функции 0x08008D48/0x08008E14; ECC-enable (+12 в init) не константа | разбор A, чтение NAND с платы, анализ spare |
| 10 | Образ A подробно (GPIO-настройка, обновление, FAT/FLASH) | A_main 0x08000174; `GPIO_Init` из B в A отсутствует | дальнейшая трассировка 0x08005E9E, 0x0800687C, 0x080052CC, 0x080058AA, 0x08006686 |
| 11 | Скорость SPI после инициализации SD | `SD_SetSpeed(1)` 0x08014B92 | разбор 0x08014B92/0x080116C0 |
| 12 | Сектора SD: CMD17/24, токены, таймауты | 0x08014F12, 0x08014F44, 0x08014FA8 | трассировка |
| 13 | Код вывода текста/кнопок/виджетов, DMA для LCD (не найден) | `LCD_FillRect` 0x080154D4 не перепроверен | трассировка вызывающих LCD_SetWindow |
| 14 | SPI3/DMA2_Ch2/EXTI/SysTick код без вызовов | 0x08017DCE, 0x08017F54, 0x0801069C, 0x08017198 | поиск вызова через указатели (33 косвенных вызова; цели не разрешены) |
| 15 | Косвенные вызовы BLX (33), таблица переходов (1) | `functions.json: indirect_calls` | ручная трассировка таблиц указателей |
| 16 | Полнота обнаружения кода | 1126 функций через recursive descent + gap scan + указатели; gap-scan может принять данные за код (строки отфильтрованы по ADR/литералам) | сравнить с Ghidra/IDA |
| 17 | Точность единицы `delay_ms_tim2` | 0,6 мс при 120 МГц, 1 мс при 72 МГц | измерить период TIM2 на плате |
| 18 | UTF-16/GBK строки | 7 / 67 совпадений, вероятно ложные | ручная проверка |
| 19 | Версия «v0.0.2» из задания | в бинарнике найдена `MEGA_PRO 2020.9.3` (0x0801A45F) | сверить с источником дампа |

**Можно проверить на плате:** IDCODE; осциллограф/логический анализатор: UART (PA9/PA10), FSMC (A20/NWE/NOE), SPI2, PC4; чтение NAND (ID, дамп); дамп SD-карты с обновлением ресурсов.
