# UART_PRINTER — USART1 и протокол с принтером (образ B)

## Канал
| Параметр | Значение | Доказательство |
|---|---|---|
| Пины | PA9 TX (AF_PP), PA10 RX (IPU), **PA8 = reset принтера** (OUT_PP, после инициализации `SetBits` ⇒ высокий в покое) | `USART1_Init` 0x0801738A: 0x080173B8–0x080173EC |
| Параметры | **115200 бод, 8 бит, 1 стоп, без чётности, без HW flow control, Mode=TX+RX** | `USART_Init` struct @0x08017412: BaudRate=0x1C200; Parity|Mode words → Mode=0x0C |
| Прерывания | RXNE (`USART_ITConfig(USART1,0x525,1)` 0x0801743A), настройка NVIC через `0x08010316` (вызов 0x0801742E, структура в стеке; номер канала/приоритет не расшифрованы), `USART_Cmd(USART1,1)` 0x08017442 | |
| Клок | APB2 0x4005 = AFIO+GPIOA+USART1 | 0x08017390 |
| Приём | `USART1_IRQHandler` 0x08017476 → `uart_rx_push` 0x08017366: кольцо 250 байт (`0x200048B4`), индекс в `0x20000078`, счётчик строк (по LF=0x0A) в `0x2000007C` | 0x08017376 (`cmp #0xFA`), 0x0801737E (`cmp r0,#0xA`) |
| Выборка строки | `uart_get_line` 0x0801749E: до LF (≤0x78 символов); строка из одного CR/LF превращается в **"OK0"** (0x080174F2–0x080174FA); завершает NUL | |
| Передача | `uart_putc` 0x0801744A (блокирующая: DR, ожидание TC, сброс TC); форматная печать — вероятно `0x0801E0E0` (printf-подобная, вызывается с `adr`-строками, напр. 0x0801025C; цепочка до `uart_putc` через 0x08017462 **не прослежена**) | |
| Тайм-ауты/ошибки UART (ORE/FE) | **не обрабатываются** (нет чтений SR кроме RXNE/TC) | |
| Обновление прошивки принтера | **не обнаружено** (ни протокола, ни xmodem/ymodem-констант) | |

## Формат
Текстовый, строки завершаются `\n` или `\r\n`. Контрольных сумм нет (кроме номера строки/счётчика в протоколе Marlin-стиля — не обнаружено). Протокол — фирменный **Anycubic TFT ("A-коды")**; значения кодов ниже определены по контексту использования в UI, **без привязки к внешней документации** (для идентификации команд сверяйтесь с прошивкой принтера).

### TFT → принтер (строки в образе B; адрес — начало строки)
| Строка | Адрес | Контекст (ссылающаяся функция) |
|---|---|---|
| `G28`, `G1 F3000 Z100`, `G1 F6000 X%d Y%d`, `G1 X%d`, `G1 Y%d`, `G1 X%d Y%d` | 0x080102A8–0x08010300 | `0x080101EE` (тест перемещения, нет вызовов) |
| `A8 S%d`, `A8 S0` | 0x08018AD4, 0x08018500, 0x08018AE4, 0x08018D18 | выбор/старт файла (рядом с `A13 %s`) |
| `A13 %s` | 0x08018CFC | имя файла (используется функцией 0x08018C70 с «.bmp») |
| `A51 H/I/J/K/L` | 0x08019108–0x08019128 | пакет из 5 команд (UI) |
| `A21 C/X/Y/Z` | 0x080195F0, 0x0801A990–0x0801A9B0 | кнопки Home (все/X/Y/Z) |
| `A16 C230`, `A16 S%.0f`, `A17 S%.0f`, `A18 S%d`, `A20 S%d` | 0x08019EA4, 0x0801CD2C, 0x0801CD3C, 0x0801CED0, 0x0801CEDC | задание температур/вентилятора/скорости |
| `A22 E +30 F300`, `A22 E -30 F400` | 0x08019ED0, 0x08019EE0 | выдавить/втянуть пруток |
| `A22 X/Y/Z ±0.1/±1/±10 F%d` (18 строк) | 0x0801A47C–0x0801A58C | ручное перемещение |
| `A37 S0/S1`, `A43 S0/S1` | 0x0801C30C–0x0801C364 | включение/выключение функций |
| `A38 S%d`, `A40 S%.2f`, `A41 S%d`, `A42 S%d`, `MCA39 S%.2f` | 0x08019A2E–0x08019A64 | настройки (напр., калибровка/смещения) |

### Принтер → TFT (разбор в `Main_Task_Comm_Parse` 0x0801C3FC)
Токены `A0V … A7V`, `A20V`, `A44V`, `A45V`, `J33 ` и маркер `END` (0x0801C42A) сравниваются в 0x0801C574–0x0801C7EC. Расширения файлов `.GCO/.gcode/.BMP/.bmp` — фильтр списка файлов, получаемого по протоколу (0x0801C454–0x0801C4CC). Смысл каждого токена **не расшифрован** (UNRESOLVED).

### Сообщения UI о состоянии печати
См. STRINGS_AND_RESOURCES.md (напр., «Printing done,took:%dH %dM» 0x0801B120, «T0 senser abnormal» 0x0801AF18, «Lack of filament…» 0x0801B158).
