# SOFTWARE_ARCHITECTURE

## Общая картина
Флеш содержит **две независимые программы**, собранные Keil/ARMCC (по стилю: scatter-load таблицы `Region$$Table`, libc-хелперы, SPL-функции без `--split_sections`: неиспользуемые функции библиотеки остались в образе):

```
0x08000000  Образ A — загрузчик / обновлятор (~60 КБ)      MSP=0x20007FC8  Reset=0x080096E9
0x0800F000  свободно 4 КБ (0xFF)
0x08010000  Образ B — приложение TFT (~78 КБ)             MSP=0x20006C08  Reset=0x0801CFB1
0x0803E860  блок настроек (100 Б, чтение с 0x0803E864)
```

## Образ A: `A_main_bootloader` 0x08000174 (подтверждено чтением)
1. `0x08000144(0x3E8)`, `0x080097EA` (обращается к SCB), `0x08008814` — подготовительные вызовы (**назначение не расшифровано**);
2. `0x08005E9E`: если вернула **ненулевое** значение (`cbnz r0`, 0x0800018E) — сразу к проверке приложения; если **0** — вызываются `0x0800687C`, `0x080052CC`, `0x080058AA` (**вероятно путь обновления с SD**: в A присутствуют код FAT/SD-SPI2, NAND-драйвер (0x08008B0A…), Flash unlock/erase/program (0x080006AA…) и строки «Erase %d/%d» (0x08009157), «Touch Screen Adjust OK!» (0x080080FF) — но ссылающиеся на строки функции не определены);
3. Проверка приложения: `(*(u32*)0x08010000 & 0x2FFE0000) == 0x20000000` (0x0800019C–0x080001AC); затем `MSR MSP,*(0x08010000)` и `blx *(0x08010004)` (0x080001B0–0x080001CC);
4. Иначе экран « no user Program» (0x0800020F) через `0x08006686(0x18,0x96,str,…)` и бесконечный цикл.
В A **нет** переадресации прерываний: VTOR=0x08000000 (A), приложение B само ставит VTOR=0x08010000 (0x0801014E).

## Образ B: инициализация и главный цикл (`B_main` 0x08010144, адреса — из листинга)
```
0x08010144 SystemInit            0x08010152 USART1_Init_115200   0x08010156 sub_080171F4 (PE2 как выход)
0x0801014E NVIC_SetVectorTable(0x08000000, 0x10000) -> VTOR=0x08010000
0x0801015C sub_08017222(1)  (GPIOE ODR)   0x08010164 Buzzer_TIM5_PWM_Init(0,0x28)
0x0801016E TIM2_Tick_Init(0x47,0x3E7)     0x08010172 LCD_Init_ILI9488   0x08010176 Touch_GPIO_Init
0x0801017A DAC_Init_PA4                   0x0801017E NAND_GPIO_FSMC_Init   0x08010182 SD_Init
0x08010186 если SD OK: SD_ReadConfig(0x08014250); если [0x20000020] > 6 -> NAND_Erase_Progress, SD_to_NAND_Loader,
           затем картинки 0x41..0x70 по 200 тиков, пауза 1000
0x080101C0 Param_ReadFlash(0, 0x200067A0, 25 слов)   0x080101C4 Show_All_Images_Test (картинки 0..0x3C, пауза 3000)
0x080101C8 sub_08018430()  (однократно)
loop 0x080101CC: sub_08018480(); sub_0801723A(); Main_Task_Comm_Parse(); Main_Task_UI(); b loop
```
* **Модель выполнения:** суперцикл (без RTOS: нет PendSV/SVC обработчиков, SysTick не используется), событийность через флаги в RAM и два прерывания: **TIM2** (тик/таймаут зуммера) и **USART1 RXNE** (кольцевой буфер). EXTI/DMA-обработчики присутствуют в таблице, но не включаются.
* **Задачи цикла:** `0x08018480` (работа с `0x2000004C/0x200000AC/0x20006378`, вызывает `0x08017300`/`0x08018538`), `0x0801723A` (GPIOE/PE… + тики: вероятно опрос кнопки/датчика), `Main_Task_Comm_Parse` 0x0801C3FC (приём ответов принтера, список файлов, температуры), `Main_Task_UI` 0x0801AD66 (экраны, сообщения, состояния печати).
* **Экранная модель:** «экраны» = полноэкранные RGB565-картинки из NAND (`Show_NAND_Image`) плюс динамический текст (форматные строки `%d/%d`, `%.0f`, `%.1f`) и кнопки по координатам касания; шрифтовой рендер — в мелких функциях (не идентифицирован полностью, см. UNRESOLVED).
* **Конфигурация:** блок 100 Б из Flash 0x0803E864 → RAM 0x200067A0 (`Param_ReadFlash`); **функции записи параметров** (стирание/программирование страницы 0x0803E800) — FLASH_* в B присутствуют (FLASH_IF в 54 функциях, SPL), но конкретный вызов сохранения не прослежен.
* **Watchdog:** отсутствует (нет IWDG/WWDG). **Обработка ошибок:** текстовые сообщения (SD pullout, T0 senser abnormal, Lack of filament…), `error block:` при стирании NAND.

## Глобальные переменные (RAM, выявлены по литералам; назначение — по поведению)
| Адрес | Назначение (доказательство) |
|---|---|
| 0x20000068 | структура таймера: +0 флаг обратного отсчёта, +4 счётчик, +8 **тик TIM2**, +12 обратный отсчёт зуммера (TIM2 ISR 0x080172C4) |
| 0x20000078 | состояние UART-кольца: +0 write idx, +1 read idx, +4 счётчик строк |
| 0x200048B4 | буфер UART RX (250 Б) |
| 0x2000389C | буфер страницы NAND (2048 Б) для `Show_NAND_Image` |
| 0x200067A0 | копия блока настроек (100 Б) |
| 0x2000489C | флаги тача (+8 — флаг из EXTI-обработчика, не активен) |
| 0x20000028 | рабочий буфер/адрес чтения NAND в `Show_NAND_Image` (r1 для 0x08017BDE) |

## Что принадлежит библиотекам (не прикладная логика)
SPL (GPIO/RCC/TIM/USART/SPI/FSMC/FLASH/EXTI/DAC/DMA — 78 функций имеют дубликаты в A и B, см. `functions.json: duplicate_of`), FatFs-подобная FAT32 + таблицы кодовой страницы, printf/sprintf, double-арифметика (0x0801D2B6/0x0801D34A/0x0801D3B2).
