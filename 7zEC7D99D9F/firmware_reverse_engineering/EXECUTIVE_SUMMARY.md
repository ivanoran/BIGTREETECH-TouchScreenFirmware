# EXECUTIVE_SUMMARY

**Что это.** Дамп 256 КБ содержит **две программы** (Keil/ARMCC + STM32 SPL, суперцикл без RTOS) для 3D-принтерного сенсорного TFT-контроллера (в образе B строка `MEGA_PRO 2020.9.3`, протокол «A-кодов» Anycubic):
* **Образ A, 0x08000000** — загрузчик/обновлятор: проверяет образ B (MSP∈RAM) и передаёт управление на `*(0x08010004)`; иначе выводит «no user Program». Содержит FAT/SD, NAND-драйвер, Flash-программирование.
* **Образ B, 0x08010000** — приложение: ILI9488 480×320 RGB565 через FSMC, картинки UI хранятся в NAND (3 блока на кадр), сенсор XPT2046 (bit-bang), SD по SPI2, USART1 115200 8N1 к принтеру, TIM2 тик, TIM5 PWM-зуммер.

**Подтверждено по бинарнику (с адресами):**
* Два вектора и стартовые цепочки; scatter-таблицы; ≈139,6 КБ занято, пустая страница 0x0800F000.
* Клок: HSE→PLL×15 = **120 МГц**, PPRE1=/2 → 60 МГц (SPL-код 0x0801CFD4/0x0801D040/0x0801D030); таймерная арифметика предполагает 72 МГц (TIM2 PSC 71/ARR 999 ⇒ 1 мс@72 МГц, 0,6 мс@120 МГц). Скорее всего прошивка предназначена для 120-МГц STM32F10x-совместимого кристалла (напр. GD32F303) — **не подтверждено**.
* GPIO-карта (27 вызовов `GPIO_Init` в B разобраны (часть масок — вручную)), LCD (полная последовательность ILI9488 + FSMC-тайминги ADDSET=0/DATAST=1), NAND (команды, 2 КБ страницы, формат хранения картинок), тач (программный SPI, фильтр 30 замеров/усечённое среднее), SD (CMD0/8/55+41/58/16, SPI2 /256), UART (кольцо 250 Б, строки по LF, A-коды), TIM2/TIM5.
* **Расхождения с исходной гипотезой:** (1) два образа, адреса задания — образ B; (2) тач не на SPI1, а bit-bang на PA5/PA6/PA7, CS PC4 в итоге настроен как IPU, PENIRQ PC5 опрашивается (EXTI не включён); (3) CS LCD — ручной GPIO PE3; (4) SD-карта: CD=PB11, CS=PB12 — как в задании; (5) NAND также занимает PE0 (IPU) — назначение неизвестно.

**Состояние анализа.** 1126 функций (A 533, B 593), 0 ошибок декодирования, 91,8 КБ кода покрыто; ~90 функций названо вручную (high/medium/low), остальные описаны автоматически. Полные листинг, xref, граф вызовов, периферия — в `disassembly/`.
**Не сделано / открыто:** формат шрифтов, смысл токенов ответа принтера, калибровка тача, блок настроек, подробный разбор загрузчика A, содержимое NAND (дамп не предоставлен) — см. UNRESOLVED.md.
**Главные проблемы портирования:** частота/кристалл (120 МГц), ресурсы UI только в NAND оригинала, неизвестные шрифты, фирменный протокол без документации, тайминги FSMC/задержки привязаны к тактовой частоте.
