# Дорожная карта порта BTT TouchScreenFirmware на Anycubic TFT v0.0.2

Принципы (согласованы с владельцем форка):
1. Минимальные изменения оригинального кода BTT — все новые определения через
   вариант платы (`Variants/pin_*.h` + условная компиляция), чтобы обновления
   апстрима применялись без конфликтов.
2. Каждый шаг — отдельный PR и отдельная проверка на железе.
3. Результат каждого шага — бинарник для прошивки через OpenOCD (без бутлоадера,
   VECT_TAB_FLASH=0x08000000).

## PR-0. Документация и инструменты (этот PR)
- `docs/hardware_analysis_anycubic_tft_v2.md` — результаты реверса дампа стока.
- `docs/porting_roadmap.md` — этот документ.
- `tools/firmware_analysis/` — скрипты дизассемблирования/анализа дампа
  (Capstone), которые использовались для подтверждения пинов.
- Без изменения кода прошивки.

## PR-1. Каркас варианта платы + сборка «без boot»
- Новый env в `platformio.ini`: `ANYCUBIC_TFT_V2` (STM32F103VC, HSE 8 МГц,
  `VECT_TAB_FLASH=0x08000000`, RAM 48 КБ).
- Новый файл `Variants/pin_ANYCUBIC_TFT_V2.h` (пины из таблицы анализа).
- Проверка: прошивка собирается, на железе стартует (UART-лог / мигание подсветки).

## PR-2. Дисплей: FSMC + ILI9488 + подсветка (первый видимый результат)
- FSMC Bank1: CS=PE3 (GPIO вручную), RS=A20/PE4 (окна 0x60000000/0x60200000),
  reset PE5, подсветка PC9, D0–D15, NOE/NWE.
- Обёртка CS вокруг транзакций LCD (макросы в уровне HAL — трогаем только
  stm32f10x/lcd.c и ILI9488.c).
- Первый тест: заливка экрана тестовыми цветами (как в стоке) — проверка
  без полной логики прошивки.
- Проверка на железе: картинка на экране.

## PR-3. Тач XPT2046 (бит-банг PA5/PA6/PA7, CS=PC4, PENIRQ=PC5)
- Пины в варианте платы, калибровка.
- Проверка: касания работают в меню.

## PR-4. SD-карта (SPI2 + CD PB11)
- Пины уже совпадают с BTT (PB12–PB15) — только CD и логика.
- Проверка: файлы с SD видны в меню.

## PR-5. NAND: драйвер FSMC Bank2 + эмуляция W25Qxx
- Драйвер NAND: команды 0x70010000, адрес 0x70020000, данные 0x70000000,
  CE=PD7, NWAIT=PD6, аппаратная ECC (страница 2 КБ).
- Реализация API `W25Qxx_*` поверх NAND (трансляция: сектор 4 КБ → блок NAND,
  износ/грязные блоки — простейшая карта таблиц).
- Проверка: ReadID, запись/чтение сектора, затем шрифты/иконки загружаются
  с SD в NAND, интерфейс отрисовывается.

## PR-6. UART принтера (USART1 PA9/PA10), пищалка PA2 (TIM5_CH3), reset принтера PA8
- Проверка: связь с Marlin/принтером, звук, команда сброса.

## PR-7. Полировка
- Стартовый логотип/заставка (ресурсы в NAND), калибровка таймингов FSMC,
  экономия CS-переключений (блоковые транзакции вместо по-байтовых).

## Открытые вопросы (проверить на железе)
- Линии PE13–PE15 (D10–D12 LCD): подключены ли (16-бит шина требует все 16).
- Функция PE0 (сток настраивает IPU) — кнопка? детект чего-то?
- Реальный BCR1 стока: 0x1010 (по дампу) или 0x1011 (по наблюдению на железе).
- Точная частота USART1 в стоке (вычисляется в рантайме).
