# Инструменты анализа дампа стоковой прошивки Anycubic TFT v0.0.2

Скрипты использовались для реверс-инжиниринга стоковой прошивки (подтверждение
распиновки, FSMC-конфигурации, драйвера NAND). Результаты — в
`docs/hardware_analysis_anycubic_tft_v2.md`.

## Зависимости

```bash
pip install capstone
```

## Использование

```bash
# Карта периферии в регионе дампа (литеральные пулы)
python3 fw_analysis.py dump_full.bin lits 10000 24000

# Дизассемблировать 60 инструкций с offset 0x15252 (VA 0x08015252)
python3 fw_analysis.py dump_full.bin dis 15252 60

# Найти все 32-бит литералы 0x70010000 в дампе
python3 fw_analysis.py dump_full.bin find 70010000

# Полный линейный дизассемблинг загрузчика и приложения в текстовые файлы
python3 full_disasm.py dump_full.bin ./out
```

Ключевые адреса стоковой прошивки (для навигации):

| Адрес (VA) | Что там |
|---|---|
| 0x08015252 | Сброс LCD (PE5 LOW→HIGH с задержкой) |
| 0x080153E4 | Инициализация FSMC Bank1 + GPIO LCD + SPI2/SPI3 |
| 0x0801555A | Полный init ILI9488 (гамма, SLPOUT, DISPON, подсветка PC9) |
| 0x0801527A | Хелперы записи команды/данных LCD (окна 0x60000000/0x60200000) |
| 0x0801762C | Инициализация NAND: FSMC Bank2, GPIO (PD7/PD11/PD12/PD6, PE7-10) |
| 0x080176CE | NAND ReadID (команда 0x90 через окно CMD 0x70010000) |
| 0x08016510 | Бит-банг SPI для XPT2046 (PA5/PA6/PA7) |
| 0x08016578 | Чтение координат тача (CS=PC4, 12-бит) |

Сам дамп стоковой прошивки в репозиторий **не включается** (чужой проприетарный
код) — держим его локально, скрипты принимают путь к нему аргументом.
